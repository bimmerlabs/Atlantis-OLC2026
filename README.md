# Atlantis-OLC2026
Game jam entry for OLC CodeJam 2026 - built with my in-development Pixel Poppy Engine (PPE), using the Saturn Ring Library (SRL)
<img width="1277" height="953" alt="image" src="https://github.com/user-attachments/assets/b63d5638-f055-45da-ac0d-22e4f975b8e2" />

This re-used a lot of code from my "game of life" test example.  Most of the work done was in gameplay.hpp and the Atlantis subfolder.
<img width="1276" height="952" alt="image" src="https://github.com/user-attachments/assets/8a0d20a8-1510-4f71-acdf-828bcdfe1e6e" />

I had also spent a bunch of time this summer working on PPE.
In fact, without it I definitely wouldn't been able to submit anything worthwhile :D

It is not complete or released *yet*, but check back here soon - it already does a lot:
- state handling
- screen transitions
- backup/save management
- menus
- player / input matchup
- CD audio and PCM playback / compression through Ponesound
- Sprite asset handling (compression, packing, animations) and drawing
- printing to screen using VDP1 (required for this game, since I didn't have enough NBG layers)
- ABC+Start and CD tray monitoring
